# Race Limits · Предел функции и непрерывность

Учебный сайт для 10 класса по разделу 10.3А: предел функции, первый замечательный предел, односторонние пределы, непрерывность и асимптоты. Все формулы записаны в LaTeX и отображаются через MathJax.

## Как открыть

- Локально: откройте `index.html` в браузере (нужен интернет для MathJax).
- GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.

## Страницы

| Файл | Что внутри |

## Источник задач

Все задачи взяты из сборника **Шаметова «Математика» (12000 задач)**:

- **гл. 11, §72**, № 11153–11214: пределы в точке, на бесконечности, первый замечательный предел;
- **гл. 12, §75.5**, № 11827–11841: функции, по которым поставлены вопросы об односторонних пределах, непрерывности и асимптотах.

В пособиях Рустюмовой для подготовки к ЕНТ/ҰБТ раздела о пределах нет, поэтому задачи оттуда не использовались.

Задача № 11199 б) пропущена: в книге напечатано $\lim_{x\to0}\frac{\lg 10x}{2x}$, и такой предел не существует (вероятно, опечатка вместо `tg`).

